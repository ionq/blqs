# Security Policy

## Supported versions

`blqs` and `blqs-cirq` are pre-1.0. Security fixes are applied to the latest
released version of each package only; please upgrade before reporting.

## Reporting a vulnerability

Please do not open a public issue for security vulnerabilities.

Report privately through GitHub's
[private vulnerability reporting](https://github.com/ionq/blqs/security/advisories/new)
(the **Security** tab -> **Report a vulnerability**). If you cannot use GitHub,
email <opensource@ionq.com>.

Please include a description of the issue, steps to reproduce, and the affected
package and version. We will acknowledge your report and keep you updated on the
fix and disclosure timeline.
